# Engraving Style References

This directory contains reference images from published jazz materials used for
**non-commercial development and educational purposes only** to ensure ChordFont's
engraving matches established professional standards.

## Files

### `new-real-book-chord-guide.png`

**Source:** The New Real Book (Sher Music Co.)  
**Purpose:** Reference for the "realbook" engraving style — the canonical modern jazz lead sheet standard  
**Copyright:** © Sher Music Co. — included here under fair use for development reference only  
**Use:** Visual comparison during font development; not redistributed in any product

The New Real Book's chord engraving style is the de facto standard for modern jazz
notation. This guide shows their official chord type conventions and serves as the
gold standard for ChordFont's default "realbook" style variant.

## Fair Use Rationale

These reference materials are included for:
- Non-commercial educational and development purposes
- Transformative use (creating an independent font implementation)
- Limited scope (single reference chart, not the full publication)
- No market substitute (not replacing the original work)

**Note:** ChordFont's font glyphs are derived from Petaluma (OFL), not from these
references. This guide is used only to validate that our independent implementation
matches professional engraving conventions.
